SENTINEL

Igor Eduardo · 15 September 2026 · Winner · webAI Build Challenge — Enterprise Track · 2026

The public SENTINEL work is an on-device computer vision system, trained locally on Apple Silicon with MLX and YOLO26. This note restates only what is already on the site and in the public demo.

The homepage milestones record the result as Winner · webAI Build Challenge — Enterprise Track · 2026. The system is described there as built for offline casualty triage — locally trained models, zero cloud dependency, designed for environments where connectivity cannot be assumed.

What is public
